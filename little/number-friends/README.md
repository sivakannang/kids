# 🔢 Number Friends

**Teaches:** numbers 1–10 (and up to 20): saying, recognising and counting. **Age:** 3–5.

- Learn: big number, word, and things to tap and count aloud; "Count with me".
- Find the Number: hear it, tap it.
- How Many?: count the things, pick the number.
- Trace link for writing numbers.
