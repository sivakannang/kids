# 🔤 Letter Sounds

**Teaches:** phonics: the sound each letter makes, in the Jolly-Phonics order (s a t i p n first), and the five vowel friends. **Age:** 3–5.

- Four groups of letters; each letter has a picture word and a little action ("s: hissing like a snake").
- "🎤 I said it!" button: he says the sound out loud, a grown-up listens, and he gets praise and a star (no microphone).
- Which Letter? listening game with 3 big choices.
