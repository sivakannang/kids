# 🧠 Growing Me

Games for focus, goals, dreams and imagination.

| Project | What it teaches |
|---|---|
| [focus-garden](focus-garden/) | Focusing for 1–15 minutes (a flower grows while she focuses), calm breathing, a garden of past focus sessions |
| [goal-ladder](goal-ladder/) | Small daily steps towards a goal, with a printable certificate at the top |
| [dream-jar](dream-jar/) | Drawing and saving dreams, with links to games that help each dream |
| [why-jar](why-jar/) | Collecting questions, guessing first, finding out together, and keeping the answers |
| [imagine-time](imagine-time/) | Five calm, read-aloud guided imagination journeys |

**Ideas:** kindness diary, feelings check-in, gratitude jar.
