# 🌠 Imagine Time

**Teaches:** imagination, visualising, and calming down. **Age:** 4–9.

- 5 guided journeys (Space Ride, Under the Sea, Magic Forest, Cloud Float, Butterfly Garden), read aloud slowly with floating pictures.
- "Eyes closed" mode dims the screen. Works without sound too (text only).
- A star for each journey, once a day.
