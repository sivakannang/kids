# 🪜 Goal Ladder

**Teaches:** reaching big goals with small daily steps. **Age:** 5–9.

- Pick a goal (or write one) and choose 5, 7, 10 or 14 steps.
- One step per day; she climbs the ladder. Stars for each step, a trophy and a printable certificate at the top.
- Grown-ups can add a missed step. Saved in this browser only.
