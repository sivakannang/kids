# அ Uyir Ezhuthukkal

**Teaches:** the 12 Tamil vowels (uyir ezhuthukkal), short (kuril) and long (nedil) sounds. **Age:** 4–7.

- Tap each letter to see a picture word (அம்மா, ஆடு, இலை…) with the sound written in English letters.
- Uses the device's Tamil voice if it has one (most Macs and phones do); otherwise read together.
- Quiz: first letter of a word, which letter says a sound, short vs long.
