# ⏰ Tick-Tock World Explorer

Learn to read an analog clock while travelling the world.

- **World Clock:** tap one of 25 cities on the map; the clock jumps to that city's time. Digital time is hidden until she taps 👀 to check her answer.
- **What's the Time?:** read the clock, pick the right answer (5 levels).
- **Set the Clock:** drag the hands to show a given time.

**Age:** 5–8 · **Default city:** Bangalore · **Time format:** 12-hour AM/PM
Uses `../../shared/` for styles, stars, sounds and the offline map files.
