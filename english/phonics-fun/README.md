# 🔊 Phonics Fun

**Teaches:** letter names and sounds (phonics). **Age:** 4–6.

- Alphabet board A–Z with a picture word for each letter, read aloud ("B is for ball"). Short vowel words: ink, octopus, umbrella. X uses "box" (X at the end).
- First Sound quiz: which letter does the word start with?
- Find the Letter: hear a letter, tap it among 6.
- Kuyil's 5 challenges.
