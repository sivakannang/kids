# 🔊 Phonics Fun

**Teaches:** letter names and sounds (phonics). **Age:** 4–6.

- Alphabet board A–Z with a picture word for each letter. Tapping a letter plays its SOUND, not its name ("B says buh, buh, ball"). Sounds and words come from the shared phonics table in `shared/kids.js` (`Kids.phonics`), the same one ChinnaKutty's games use. X uses "box" (X at the end).
- First Sound quiz: which letter does the word start with?
- Find the Letter: hear a letter, tap it among 6.
- Kuyil's 5 challenges.
