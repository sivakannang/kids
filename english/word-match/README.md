# 🧩 Word Match

**Teaches:** reading Class 1 words. **Age:** 5–7.

- Topics from the Class 1 word lists: fruits, animals, food, school, nature, home, colours.
- Picture → Word and Word → Picture quizzes (8 per round, with read-aloud).
- Spell It: tap the letter tiles in order to spell a word (two extra letters to make it tricky).
