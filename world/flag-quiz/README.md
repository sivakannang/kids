# 🚩 Flag Quiz

**Teaches:** flags, countries, capitals, continents, and hello in other languages. **Age:** 5–9.

- Explore 29 countries grouped by continent: flag, capital, continent, how to say hello.
- Quiz: flag → country, country → flag, which continent, capital city.
- Flags are emoji: they show on Mac, iPhone, iPad and Android, but Windows shows letters instead.
