# 🗣️ Word Explorer

**Teaches:** the same words in English, Tamil, Hindi and Kannada. **Age:** 5–9.

- Topics: home, animals, nature, fruits, numbers 1–10, colours, days of the week.
- Each word in all four scripts with English-letter sounds and 🔊 (or "read it together" if the device has no voice for a language).
- Quiz in Tamil, Hindi or Kannada.
